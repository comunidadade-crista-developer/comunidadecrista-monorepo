# Código de Conduta

Este projeto segue o [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Resumo: trata todos com respeito. Não são tolerados assédio, discriminação, ataques pessoais ou conteúdo que viole a doutrina cristã historicamente partilhada pelas igrejas evangélicas.

Reporta problemas para **conduct@<domínio>** (a configurar).
